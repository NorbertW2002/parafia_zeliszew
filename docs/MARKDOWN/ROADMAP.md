# ROADMAP

> Version: 1.0
> Project: Parish Starter
> Last Updated: 2026-08-07

---

# Overview

This document outlines the planned development of the Parish Starter project.

The roadmap provides general direction rather than fixed deadlines or release dates.

Features may change as the project evolves.

---

# Vision

Parish Starter aims to become a modern, lightweight and reusable website starter for Polish Catholic parishes.

The project focuses on simplicity, maintainability and ease of content management.

Every new feature should support these goals.

---

# Development Stages

## Stage 1 – Foundation

The primary objective is to establish a solid technical foundation.

### Planned features

- Astro project setup
- Vue integration
- Tailwind CSS
- Directus integration
- Markdown support
- Basic layouts
- Navigation
- Footer
- Homepage
- Responsive design
- Basic SEO

Status: Planned

---

## Stage 2 – Core Content

The goal of this stage is to provide all essential parish information.

### Planned features

- Parish history
- Sacraments
- Parish office
- Contact page
- Priests
- Parish groups
- Announcements
- Events
- Mass intentions

Status: Planned

---

## Stage 3 – Media

The goal is to enrich the website with multimedia content.

### Planned features

- Photo galleries
- Homepage highlights
- Image optimization
- Lightbox gallery

Status: Planned

---

## Stage 4 – User Experience

The focus shifts to improving usability.

### Planned features

- Search
- Event calendar
- Better navigation
- Breadcrumbs
- Accessibility improvements
- Performance optimizations

Status: Planned

---

## Stage 5 – Future Enhancements

Features that may be implemented in the future if they provide value.

Possible additions include:

- Livestream integration
- Cemetery map
- Online forms
- Multilingual support
- Parish bulletin
- Google Calendar integration
- PWA support

These features are optional and should only be implemented if they align with the project's goals.

---

# Development Priorities

When planning new features, the following priorities should be considered:

1. Simplicity
2. Maintainability
3. Accessibility
4. Performance
5. User experience

New features should not introduce unnecessary complexity.

---

# Success Criteria

The project can be considered successful if it:

- is easy to maintain;
- is easy to deploy;
- provides excellent performance;
- allows parish staff to update content easily;
- can be reused for multiple parishes.

---

# Out of Scope

The project does not aim to become:

- a social network;
- an online shop;
- a parish management system;
- a financial management platform;
- a replacement for the parish office.

Features outside the project scope should not be implemented unless the project goals change.
